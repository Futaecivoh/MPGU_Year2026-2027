# Дорожная карта и трекер задач — как открыть

В папке `docs/` лежат два формата плана проекта:

- **[roadmap.html](./roadmap.html)** — главный интерактивный вариант (диаграмма Ганта, фильтры по ролям и вехам, прогресс, карточка каждой задачи с критерием готовности). Работает полностью автономно, без интернета и без установки программ.
- **[PROJECT_TRACKER.md](./PROJECT_TRACKER.md)** — текстовая версия в Markdown + Mermaid для быстрого просмотра прямо на GitHub.

---

## Как открыть всей команде

### Вариант 1 — локально в любом браузере (самый быстрый)
1. Обновите репозиторий:
   ```bash
   git pull
   ```
2. Откройте папку `docs/` в Проводнике (Windows) или Finder (macOS).
3. Дважды кликните по файлу **`roadmap.html`** — он сразу откроется в Chrome, Edge, Firefox или Safari.

> **Совет:** файл `roadmap.html` полностью автономный. Его можно даже просто переслать в Discord или Telegram — у любого участника команды он откроется таким же красивым и интерактивным одним кликом.

### Вариант 2 — прямо на GitHub (без скачивания)
Откройте файл [`docs/PROJECT_TRACKER.md`](./PROJECT_TRACKER.md) в веб-интерфейсе GitHub. GitHub автоматически отрисует диаграмму Ганта и таблицу задач.

### Вариант 3 — общая веб-ссылка для команды через GitHub Pages (по желанию)
Если хотите, чтобы диаграмма открывалась по постоянной ссылке в браузере у всех (и обновлялась автоматически после `git push`):
1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку (`main` или `dev`) и папку **`/docs`**, нажмите **Save**.
4. Через 1–2 минуты страница будет доступна по адресу:
   `https://futaecivoh.github.io/MPGU_Year2026-2027/roadmap.html`

*(Примечание: для бесплатного аккаунта GitHub Pages работает на публичных репозиториях.)*

## Как пользоваться `roadmap.html`

- **Фильтры сверху:** можно отфильтровать задачи по вехе (`M1`, `M2`), по своей роли (`Программист`, `Дизайнер`, `Нарратив / Текст`, `Аналитика / Команда`), по статусу или найти задачу через поиск.
- **Детали задачи:** нажмите на любую строку или полосу на диаграмме — снизу раскроется карточка задачи с точными датами, длительностью, статусом и критерием готовности (DoD).
- **Переключение вида:** в правом верхнем углу можно выбрать `Всё вместе`, `Только график` или `Только таблица`, а также переключить светлую/тёмную тему.

## Как обновить прогресс или добавить задачу

1. Откройте `docs/roadmap.html` в любом текстовом редакторе (VS Code, Блокнот, Rider и т.д.).
2. В начале блока `<script>` найдите объект `ROADMAP_DATA` (список `milestones` и массив `tasks`).
3. Измените нужные поля (`progress`, `status`, `start`, `end`) или добавьте новую задачу по образцу:
   ```js
   {
     id: "M2-04",
     milestone: "M2",
     title: "Название задачи",
     role: "Дизайнер",
     start: "2026-12-05",
     end: "2026-12-09",
     status: "В работе", // "Бэклог" | "К выполнению" | "В работе" | "Готово"
     progress: 25,
     dod: "Что должно быть готово для закрытия задачи"
   }
   ```
4. При желании обновите те же строки в `docs/PROJECT_TRACKER.md` и сделайте `git commit` + `git push`.
